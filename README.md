# System-for-automatic-detection-of-the-last-touch-in-a-basketball
The main goal of this work is the design of a system for automatic detection of the last contact with the ball using UWB localization, with precise identification of the player who last touched the ball. The final system architecture includes dedicated printed circuit boards designed for the sensor module inside the ball, the wearable player module, and the stationary module mounted on the backboard structure, while the functionality of the basic algorithms for contact detection, distance measurement, and data transmission was experimentally verified using a laboratory prototype based on available development modules.In addition to the hardware component, a significant part of the work involves the development of a software application for the graphical display and real-time monitoring of events. The application provides an immediate overview of which player, identified by a unique ID, was the last to touch the basketball. The software application consists of a central table displaying all registered contacts, drop-down menus for quick team selection and monitoring of active players, as well as an interactive Start/Stop control system. The Stop button prevents further incoming data from being recorded in the table when the ball leaves the court, thereby preventing irrelevant contacts occurring outside the game from being registered. The Start button reactivates data acquisition when the game resumes.
